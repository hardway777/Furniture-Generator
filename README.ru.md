# Furniture Modular Generator

Furniture Modular Generator — это процедурный инструмент моделирования для Blender, предназначенный для художников окружения, дизайнеров уровней и создателей архитектурной визуализации. Он позволяет быстро создавать параметрические модульные кухни, шкафы-гардеробы и системы хранения для гостиной прямо в Blender с готовыми конвейерами экспорта в игровые движки, такие как Unreal Engine.

## Возможности

- Процедурная генерация мебели для модульных кухонь, шкафов и систем хранения
- Гибкое сочетание секций: стандартные шкафы, угловые модули, островные секции, секции с раковиной и встроенные приборы
- Поддержка прямых, L-образных и U-образных компоновок
- Встроенный экспорт для игровых движков, включая инструменты Bake для Unreal Engine и автоматические коллайдеры
- Поддержка PBR-материалов с автоматическим подключением текстур и кастомными наборами карт
- Живой предпросмотр при изменении параметров
- Управление пресетами для сохранения и повторного использования настроек и сценариев отладки

## Установка

1. Скачайте последнюю сборку из `BUILD/FurnitureGenerator-<version>.zip`
2. Откройте Blender и перейдите в `Edit → Preferences → Add-ons`
3. Нажмите `Install from Disk...` и выберите скачанный архив
4. Включите аддон `Furniture Generator`

Этот аддон рассчитан на Blender 5.2 и выше.

## Быстрый старт

1. Откройте Blender и создайте новую сцену
2. Откройте боковую панель (`N` panel) и выберите вкладку `Furniture`
3. Настройте основные параметры шкафа: глубина, высота, количество секций
4. Нажмите `Generate`, чтобы создать мебельную компоновку
5. Используйте панель отладки, чтобы загрузить встроенные тестовые сценарии и быстро проверить геометрию

### Основные параметры

- Depth — глубина шкафа
- Height — высота базового шкафа
- Section Count — количество модульных секций
- Live Preview — автоматическая регенерация при изменении значений
- Wall Thickness — толщина стенок и панелей

## Типы секций

- Standard section — обычный шкаф с дверями или ящиками
- Corner section — специальная угловая компоновка
- Island section — мебель, стоящая отдельно от стены
- Sink section — шкаф с вырезом под раковину
- Wardrobe section — система хранения с полками и штангой
- Appliance section — специализированный модуль для встроенной техники

## Экспорт в Unreal Engine

Используйте операцию `Bake`, чтобы подготовить сгенерированную модель к экспорту:

1. Откройте панель `Bake`
2. Задайте префикс имени, например `Kitchen_01`
3. При необходимости разделите верхние шкафы
4. Нажмите `Bake for UE`

Результат включает:

- Объединённые меши корпуса для статической геометрии
- Отдельные меши для дверей и ящиков
- Коллайдеры UBX для рабочих процессов физики
- Empty-объекты-сокеты для экспорта
- Сгенерированный отчёт о результате Bake
- `<bake>_doors.csv` — все двери, сокет каждой двери, размер панели и трансформ сокета; импортируется в UE как DataTable
- `<bake>_drawers.txt` — насколько может выехать каждый ящик

## PBR-материалы

Чтобы добавить кастомные PBR-материалы:

1. Поместите файлы в папку `Files/textures/`
2. Назовите их по схеме вашего материала, например:
   - `T_WoodDark_01_BaseColor.jpg`
   - `T_WoodDark_01_Normal.png`
   - `T_WoodDark_01_Roughness.png`
   - `T_WoodDark_01_Metallic.png`
3. Обновите `Files/textures/materials.txt`, чтобы сопоставить материалы с наборами карт
4. Узлы материалов будут автоматически подключены при генерации модели

## Примечания по проекту

### Коллайдеры

- Коллайдеры хранятся в отдельной дочерней коллекции, а не смешаны с видимой мебелью
- UBX-коллайдеры пересоздаются и переориентируются после изменения компоновки
- Генерацию коллайдеров можно отключать для предпросмотра без физики

### Углы и острова

- Компоновки углов и островов являются взаимоисключающими по дизайну
- Размеры угловых секций вычисляются по соседним секциям, а не задаются пользователем
- Островные секции не получают настенные панели и стандартные стеновые бордюры

### Правила импорта модулей

В кодовой базе используется стабильный порядок импорта, чтобы избегать циклических зависимостей:

```text
strings → core → mesh_ops → primitives → solver
                                  ↓
                    sections ← row
                       ↓
           properties ← operators
                ↓
        debug_scenes ← panels ← __init__.py
```

См. `AGENT_NOTES.md` для точных правил и ограничений.
